# Sample question to try

Paste this when the Whisperer asks for the question:

```
A company wants its chatbot to answer questions using its internal policy
documents, which are updated every week. The company does not want to retrain
the model. Which approach should it use?

A. Fine-tuning the foundation model
B. Retrieval Augmented Generation (RAG)
C. Increasing the temperature parameter
D. Pre-training a new foundation model
```

- Which option did you pick? `A`
- Correct option: `B`
